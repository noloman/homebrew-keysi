# Keysi's Homebrew tap

```sh
brew install --cask noloman/keysi/keysi
```

Keysi is a menu bar cheat sheet for the keyboard shortcuts of whatever app
you are in — hold ⌘ and they appear. <https://keysi.io>

`Casks/keysi.rb` is generated by `scripts/cask.sh` in the Keysi repository
at release time and pushed here. Editing it in place is pointless: the next
release overwrites it. Fix the template instead.

Keysi updates itself through Sparkle, so the cask is `auto_updates true`.
`brew upgrade` will not fight the app's own updater, and an app that has
updated itself is not reported as an outdated cask.
